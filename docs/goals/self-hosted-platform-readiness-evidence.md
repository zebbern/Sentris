# Self-Hosted Platform Readiness Evidence

This is the persistent verification ledger for
`docs/goals/self-hosted-platform-readiness.md`. A criterion is complete only
when the cited evidence proves the full requirement. Green unit tests alone do
not prove a production, migration, performance, or end-to-end criterion.

## Status values

- **Not proven** — required evidence is absent or contradicts completion.
- **In progress** — implementation or verification has started, but the full
  criterion is not proved.
- **Proved** — the listed current-state evidence independently proves the
  criterion.
- **Decision required** — completion needs user authority for a capability or
  performance tradeoff.

## Evidence update rules

1. Record exact commands, exit codes, and bounded relevant output.
2. Link each artifact or test to the criterion it proves.
3. Record RED and GREEN evidence for behavior changes.
4. Record performance baselines before the corresponding runtime change.
5. Preserve an explicit list of accepted risks and the capability or performance
   cost that made mitigation disproportionate.
6. Never promote a criterion from **In progress** to **Proved** using narrower
   evidence than the criterion requires.
